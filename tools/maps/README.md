# 内置地图目录

一张地图一个 `.json` 文件，**文件名排序即出场顺序**（用 `01-`、`02-` 前缀控制）。
放进来的图会由 `build_game.py` 打包成 `window.QQ_BUILTIN_MAPS`，和编辑器做的
自定义地图（localStorage `qqtang.maps.v1` / 导出 HTML 里的 `window.__QQTANG_MAPS__`）
一起出现在开局选图面板，自定义图排在内置图后面。

新增地图：复制一份现有 JSON 改内容，重新 `python tools/build_game.py` 即可。

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✓ | 唯一标识；编辑器地图的 `theme` 字段按它选默认贴图主题 |
| `name` | ✓ | 选图卡片上的中文名 |
| `sub` | ✓ | 卡片上的英文小字 |
| `rows` | ✓ | 21×12 的行字符串数组，见下方字符表；`1`/`2` 出生点各恰好一个 |
| `drop` | ✓ | 可炸障碍砸开后掉道具的概率 0~1 |
| `wall` / `pillar` / `crate` / `urn` / `chest` | ✓ | 各类格子的贴图名（assets/sucai 里的名字） |
| `floor` | ✓ | `base` 地面 / `lane` 中央走道 / `laneX` 走道列号（null=整行同色）/ `emblemAt` 徽记位置 / `emblem` 徽记贴图 / `speckle` 撒点密度 |
| `dust` / `dust2` / `debris` | ✓ | 尘土与碎片粒子色 |
| `decor` | | 随机撒的实心装饰（如 `prop-snowman`）；不给就不撒 |

## rows 字符表

| 字符 | 含义 |
| --- | --- |
| `#` | 硬墙（炸不开） |
| `P` | 立柱（炸不开） |
| `c` | 可炸障碍（木箱/冰块） |
| `o` | 陶罐（可炸；编辑器地图里会归一成 `c`） |
| `$` | 宝箱（必掉道具） |
| `s` | 雪块（可炸；也是唯一能被人物顶着推走的障碍：对正按住方向 0.05s 推一格） |
| `d` | 实心装饰（挡路但炸不开；编辑器地图里不挡路） |
| `.` | 空地 |
| `1` / `2` | 玩家 1 / 玩家 2 出生点 |

要求 21 列 × 12 行，边界一圈建议全是 `#`；两张内置图都是 180° 中心对称，
两个出生点条件完全对等，新图最好也遵守。
