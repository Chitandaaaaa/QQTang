# 素材需求单 —— 拿参考图生成像素素材的通用要求

> 像素化是"重绘"不是"缩图"：参考图的细节约 99% 会被丢弃，
> 产出像不像，取决于下面几项有没有说清楚。逐项填写，或直接说"按默认"。

## 必填四项

1. **参考图**：路径或截图（`sucai/` 下的原始参考图只留本地，不入库）。
2. **用途**：游戏内实装（决定满格、朝向、描边、对比度）还是素材库展示。
3. **尺寸规格**：
   - 默认：人物 32×48（头顶 16px 探出碰撞格）、物件/地砖 32×32、糖弹 24×24 居中一格；
   - 想要更精致可指定 48×48 / 64×64（画布翻倍是"更像参考图"的最大杠杆，但游戏渲染比例要同步调）。
4. **识别点（按优先级列出必须保留的特征）**：例「精灵耳 > 腰带蓝宝石 > 金镯」。
   这一项决定"像不像"——没写就由生成方自行取舍，是产出跑偏的头号原因。

## 选填（有默认值）

5. **调色板**：默认沿用 SHARED 共用 9 色 + 每材质 2~3 档（主/亮/暗），整张 8~16 个 key；
   可以给 hex，也可以说"从参考图取色"。加 key 优先加在"语义"上（眼睛高光、金属、宝石），
   不是把渐变切更碎。
6. **视图数量**：默认单视图；行走图给 正面 / 右侧面 / 背面 三视图，左向自动镜像（`mirror_left`）。
7. **命名**：`assets/sucai/<key>.svg` 的 key，默认英文小写-连字符（如 `zelda-front`）。
8. **验收**：默认 `check_sprites.py`（满格/出格检查）+ 截图对比参考图给你过目；角色类加剪影检查。

## 执行流程（生成方照此做）

```
读图取色 → 写点阵函数（tools/sucai_*.py / build_chars.py / spec_db.py）
→ python tools/build_v2.py 生成初稿
→ 截图与参考图并排对比 → 按识别点优先级精修（直接改 assets/sucai/*.svg，文件即真源）
→ 再跑 build_v2.py → python tools/run_test.py 回归
```

## 调色板速查

| 画布 | 合理 key 数 | 备注 |
|---|---|---|
| 32×32 / 32×48 | 8~16 | 现行规格；色阶带 1~2px，再多发糊 |
| 48×48 | 12~20 | 细节翻倍 |
| 64×64 | 16~24 | GBA 塞尔达量级 |
